浮光微境 · Floating Terrarium
==============================

这是完整离线包，包含场景、字体、Three.js 运行库、预览截图和完整源码。
无需安装任何软件，也无需联网。

【最简单的方式】
1. 将整个压缩包解压到任意文件夹。
2. 双击打开 START-HERE.html。
3. 建议使用 Chrome / Edge / Safari 16+ 或 Firefox 最新版，
   并确认浏览器硬件加速已开启。

双击打开的是“单文件离线版”：所有 JavaScript、字体、材质和场景都内嵌在
START-HERE.html 中，不会请求网络，也不需要 Python。

如果双击后显示“微境未能如约展开”，说明当前浏览器未启用 WebGL 2 或硬件
加速。请升级浏览器并在设置中开启硬件加速，然后再试。

【交互】
- 拖拽：环绕观察
- 滚轮 / 手机双指捏合：缩放
- 双击 / R 键：复位镜头
- 右上角「昼夜流转」或空格键：暂停 / 继续时间
- 底部时间滑杆：手动调节时间
- 页面默认停在斜阳时分；完整昼夜循环约 7 分钟

【高级运行：使用源码】
source/ 中是模块化源码。因为浏览器对 file:// 模块有限制，若要直接修改源码，
建议通过本地 HTTP 服务打开：

  cd source
  python3 server.py 4179

然后访问 http://127.0.0.1:4179/ 。Windows 用户也可以使用：

  py -m http.server 4179

或使用任意等价静态服务器。
