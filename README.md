# 浮光微境 · A Floating Terrarium

一方悬浮于深空的透明玻璃微缩世界。完整离线交付包，包含：

- `START-HERE.html`：单文件离线版，内含全部 JavaScript、字体与程序化场景，双击即可在支持 WebGL 2 的现代浏览器中运行。
- `previews/`：桌面日景、夜景、移动端预览图。
- `source/`：完整的模块化源码（HTML / CSS / JS / Three.js / 字体 / 本地服务器）。
- `THIRD_PARTY_NOTICES.md`、`FONT-OFL.txt`：依赖与字体许可。

## 快速开始

**无需安装任何东西**：解压后双击 `START-HERE.html` 即可。

如果需要用本地服务器调试源码：

```bash
cd source
python3 server.py 4179
```

然后访问 <http://127.0.0.1:4179/>。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 在等距视角附近环绕观察 |
| 滚轮 / 双指捏合 | 推近 / 拉远 |
| 双击 / `R` | 回到默认镜头 |
| 右上角「昼夜流转」/ `Space` | 暂停 / 继续昼夜循环 |
| 底部时间滑杆 | 手动调节时间 |

默认停在约 16:19 的斜阳时分。完整昼夜循环约 7 分钟；支持 `prefers-reduced-motion`，此时自动播放默认暂停。

## 场景内容

玻璃立方体、悬浮岛、程序化雪山、森林、草甸、河流、湖泊、瀑布、木屋、码头、石桥、苔石、野花、蘑菇、睡莲、鹿、鸭、兔、蝴蝶、飞鸟、云朵、薄雾、萤火虫和玻璃边缘折射微光。自写后期管线包含柔和高光泛光、移轴景深、体积光、ACES 色调映射、暗角与胶片颗粒。

## 浏览器要求

推荐最新版 Chrome / Edge / Safari 16+ / Firefox，支持 WebGL 2，并开启硬件加速。移动端已适配竖屏并支持双指缩放。

完整源码说明见 `source/README.md`。
